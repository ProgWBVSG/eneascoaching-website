# Directiva: Documentar Estilos

## Objetivo
Centralizar la información de diseño (colores, fuentes) para asegurar consistencia visual.

## Entradas
- `index.html` (Configuración Tailwind)

## Salidas
- `style_guide.md`

## Pasos
1. Inspeccionar `index.html` para encontrar la configuración de Tailwind.
2. Extraer códigos hexadecimales de colores y fuentes.
3. Documentar hallazgos en `style_guide.md`.
